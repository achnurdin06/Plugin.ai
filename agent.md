# Agent Skills for Building Plugin.ai AI Helpdesk & Recommendation Chatbot

## Core Development Skills
1. **Full‑Stack TypeScript** – Proficiency in TypeScript for both frontend (React/Next.js) and backend (NestJS).  
2. **React & Next.js** – Building a lightweight embeddable widget library and a feature‑rich admin portal with server‑side rendering and API routes.  
3. **NestJS (Node.js)** – Designing a modular, scalable API gateway, LLM router, token‑quota engine, and background workers.  
4. **Prisma + PostgreSQL + pgvector** – Defining schema, migrations, and implementing hybrid vector‑search for RAG.  
5. **BullMQ / Redis** – Asynchronous task processing for document ingestion, embedding, and webhook notifications.  
6. **OpenTelemetry** – Instrumentation for distributed tracing, metrics, and logging across all services.  
7. **Docker & Kubernetes** – Containerization, Helm chart creation, and deployment pipelines for cloud‑native operation.  
8. **CI/CD (GitHub Actions / Nx Cloud)** – Automated testing, linting, build caching, and release workflows.  
9. **Testing Frameworks** – Jest for unit tests, Playwright for end‑to‑end UI tests, and property‑based testing for prompt stability.  
10. **Security & Compliance** – Implementing JWT auth, origin whitelisting, PII scrubbing, prompt‑injection guardrails, and GDPR/CCPA data‑retention policies.

## AI‑Specific Skills
1. **LLM Provider Integration** – Experience with OpenAI, Anthropic, Gemini, Groq, Azure OpenAI, and local models (Ollama/vLLM).  
2. **LLM Orchestration & Fallback** – Building a router that selects providers, applies circuit‑breakers, and caches responses.  
3. **Retrieval‑Augmented Generation (RAG)** – Document parsing, chunking, embedding generation, hybrid (dense + BM25) search, and re‑ranking.  
4. **Prompt Engineering & Persona Studio** – Designing system prompts, guardrails, versioning, and sandbox testing.  
5. **Human‑in‑the‑Loop & Escalation** – Designing handoff flows to ticketing systems (Zendesk, Freshdesk) and live‑agent chat.  
6. **Token Accounting & Cost Guardrails** – Real‑time token tracking, quota enforcement, and cost alerting.
